# 4たくクイズ（小学生むけ）

小学生向けの4択クイズゲームです。PWA なので、スマホやタブレットのホーム画面に追加してアプリのように使え、オフラインでも遊べます。
まずは **小学5年生** 向けの問題を収録しています。

## モード

| モード | 内容 |
| --- | --- |
| 📝 テスト対策モード | 国語・算数・理科・社会（5年生の学習内容）。教科別 or 全教科ミックス |
| 💡 ざつがくモード | いきもの・世界/宇宙・からだ/くらし・スポーツ/あそび |
| 🔤 えいごモード | 英検5級・英検4級レベル（単語・文法・会話） |

問題数：国語139・算数120・理科104・社会103、いきもの104・世界/宇宙100・からだ/くらし100・スポーツ/あそび101、英検5級124・英検4級113（合計1108問）

- 1回10問。問題も選択肢の並びも毎回シャッフル
- 答えるとすぐに ⭕/❌ と解説を表示、最後に全問のふりかえり
- まちがえた問題は「ふくしゅう」で解き直せる（正解すると外れる）
- 分野ごとのさいこう記録、効果音オン/オフ（端末内の localStorage に保存）

### 育成キャラ

- 国語・算数・理科・社会・英語（5教科・全703問）のうち、**一度でも正解した問題の割合（習得率）**で成長します
- 全11段階（たまご → … → でんせつのはかせ）。進化に必要な習得率は 2・5・9・15・23・33・45・60・78・100% で、最初は進化しやすく、だんだん進化しにくくなります（`js/chara.js` の `THRESHOLDS` で調整できます）。進化のときは演出が入ります
- ホーム画面で、すがた・習得率・つぎの進化まであと何問か・しんかのきろくが見られます（なまえも変えられます）
- クイズ中は問題の右がわで応えん（解説やボタンとは重なりません）。正解するとよろこび、まちがえると悲しみます
- 雑学モードの問題は成長には数えません（キャラは応えんしてくれます）
- キャラの絵は `js/chara.js` で SVG として描いています

### データのバックアップ／ひきつぎ（ホームの「⚙️ ほごしゃの方へ」）

- 開くときに、かんたんな計算（2けた × 1〜2けた）に答えます（お子さんがまちがえて開かないように）
- **ファイルで保存**：共有画面から「ファイル」アプリ・LINE・AirDrop などに保存（共有できないブラウザではダウンロード）
- **ひきつぎコードをコピー**：記録を数百文字のコード（`QZ1-…`）にしてコピー。メモやLINEに保存しておけます
- **読みこみ**：ファイルかコードから。中身（保存した日・キャラ・正解ずみの数）を確認してから、いまの記録と**合わせます**（どちらかで正解していれば正解ずみ、最高記録は高いほう、キャラは育っているほう。記録は減りません）
- 途中で切れたコードや別のデータは、チェックしてはじきます
- ブラウザに「データを消さないで」と頼む設定（`navigator.storage.persist`）を自動で行います
- 最後のバックアップから30日たつと、ホームに小さくお知らせが出ます
- サーバーは使いません。中身は正解した問題・まちがえた問題・最高記録・キャラの名前と段階・設定だけで、個人情報は入りません（`js/backup.js`）

### デバッグモード（キャラの成長を確かめる）

- オン：タイトル「4たくクイズ」を7回つづけてタップ（3回目から「あと○回」と出ます。インストールしたアプリでも使えます）か、URL に `?debug` をつけて開く（例：https://mmishina-art.github.io/simple_quiz/?debug）。iPhone ではブラウザとホーム画面のアプリで記録が別なので、アプリではタップの方法を使ってください
- オフ：もう一度タイトルを7回タップ、パネルの「デバッグモードをオフにする」、または `?debug=0`
- ホームのいちばん下にパネルが出ます
  - すがたを見る：Lv.0〜10 のすがたと表情（ふつう・よろこぶ・かなしむ・おうえん）。記録は変わりません
  - 進化の演出を見る：好きな段階の進化演出（音つき）。記録は変わりません
  - 成長を進める：+1問・+10問・進化の1問前まで・つぎの進化まで・Lv.0 にもどす。**本当の記録が変わります**
  - 進化の音をえらぶ：レトロゲーム（ふつうはこれ）／ファンファーレ／キラキラ／ジャジャーン。点めつ中の「ためる音」と進化した瞬間の「ジングル」がセットで変わります（▶で通して試し聞き、名前をおすと決定。`js/jingles.js`、どれもオリジナル）

ビルド不要の素の HTML / CSS / JavaScript です。

## 動かし方

Service Worker は `http://localhost` か HTTPS でしか動かないので、ファイルを直接開かずにサーバー経由で開いてください。

```sh
npm start            # = python3 -m http.server 8080
# → http://localhost:8080 を開く
```

### GitHub Pages で公開

`.github/workflows/pages.yml` が、push のたびに問題データをチェックしてから GitHub Pages へ自動で公開します。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
公開URL: https://mmishina-art.github.io/simple_quiz/

## 問題の追加

問題データは分野ごとに1ファイルです。

| モード | ファイル |
| --- | --- |
| テスト対策 | `js/data/school/kokugo.js`・`sansu.js`・`rika.js`・`shakai.js` |
| 雑学 | `js/data/trivia/ikimono.js`・`sekai.js`・`kurashi.js`・`sports.js` |
| 英語 | `js/data/english/eiken5.js`・`eiken4.js` |

1問は1行で、`Q(問題文, [正解, ちがう1, ちがう2, ちがう3], 解説)` と書きます。

```js
Q('三角形の3つの角の大きさをたすと何度？', ['180度', '360度', '90度', '270度'], 'どんな三角形でも、3つの角の和は180度です。'),
```

- **正解は選択肢の先頭**に書きます（表示するときにシャッフルされます）
- テスト対策の問題は、ファイルの先頭の `grade(5)` で学年が決まります
- ふくしゅう機能が「カテゴリ＋番号」で問題を覚えているため、**新しい問題は配列の最後に追加**してください
- 追加したら `npm test` でチェックできます（選択肢が4つ・重複なし・解説あり・同じ問題文がない・`sw.js` のキャッシュ一覧にファイルがある、など）
- アプリのファイルを変えたら `sw.js` の `CACHE_VERSION` を上げてください。新しいバージョンは次に開いたときに自動で使われ、使っている最中なら「新しいバージョンがあります」と表示されます
- 更新のときは、ブラウザに残っている古いファイルを使わず必ず新しく取ってきます（古いファイルがまざると起動できなくなるため）。もし起動できなかったときは `js/boot.js` が自動でキャッシュを消して読みこみ直します（学習の記録は消えません）
- 新しいデータファイルを作ったら、`sw.js` の `APP_SHELL` にも追加してください

## 他の学年を追加するには

`js/app.js` の `CURRENT_GRADE` で出題する学年を決めています。`grade` を変えた問題を追加し、学年選択の UI を足せば対応できます。

## ファイル構成

```
index.html             画面（ホーム / 分野選択 / クイズ / 結果）
css/style.css          スタイル（背景はあんず色・白いカード。スマホのダークモード設定に関係なく、いつも明るい画面）
js/boot.js             起動係（オフライン対応の登録・更新のお知らせ・起動できないときの自動修復）
js/app.js              ゲームの進行
js/data/                問題データ（school/ trivia/ english/ に分野ごとのファイル）
js/storage.js          記録の保存
js/sound.js            効果音（Web Audio）
js/jingles.js          進化のジングル（金管・ベル・ドラム・リバーブで作るオリジナル曲）
js/chara.js            育成キャラ（SVGの絵・進化の段階・セリフ）
js/debug.js            デバッグモード
js/backup.js           データのバックアップ／ひきつぎ
sw.js                  Service Worker（オフライン対応）
manifest.webmanifest   PWA の設定
icons/                 アプリアイコン（icon.svg が元データ）
scripts/validate-questions.mjs  問題データのチェック
```
